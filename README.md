# AndroidApp (Flash Card App)

An alternative to Quizlet focused on fast memorizing, especially for language learning.

## Functionality
- Create, edit, and delete a deck of flash cards
- Add and delete cards inside a deck
- Flip-card study mode
- Quiz mode
- Progress tracker for each deck
- Cards marked "don't know" appear more often during review
- Categories/tags for organizing decks
- All data is saved locally on the device

## Project structure
app/
src/main/java/com/example/androidapp/ - app source code
src/main/res/ - resources (layouts, strings, images)
src/androidTest/ - instrumented tests
src/test/ - unit tests
build.gradle.kts - project build configuration
settings.gradle.kts - project settings

## Build & run
1. Open the project in Android Studio
2. Let Gradle sync finish
3. Click Run (or Shift+F10) to build and launch on an emulator or device
